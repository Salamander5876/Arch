Это отличная идея. Устанавливать Arch через SSH гораздо удобнее: можно просто копировать команды из этого чата, не вбивая их вручную в консоль.

Вот обновленный гайд "Путь Самурая через SSH".

---

## Шаг 0: Подготовка (из Windows/macOS)
1.  **Запиши ISO:** Rufus (в режиме **DD**) или Ventoy.
2.  **BIOS:** Отключи **Secure Boot**, режим **UEFI**.

---

## Шаг 1: Настройка SSH на Arch (на «железе»)
Загрузись с флешки. Когда появится командная строка, сделай следующее:

1.  **Интернет:**
    * **Кабель:** Подцепится сам.
    * **Wi-Fi:** `iwctl` -> `station wlan0 connect SSID` (подробности в старом гайде).
2.  **Установи пароль для root (только для сессии установки):**
    Введи `passwd` и напиши простой пароль, например `123`.
3.  **Узнай IP адрес:**
    Введи `ip addr`. Ищи строку `inet` (например, `192.168.1.45`).
4.  **Запусти SSH:**
    `systemctl start sshd`

---

## Шаг 2: Подключение с основного ПК
Теперь садись за свой обычный компьютер, открывай терминал (PowerShell или CMD в Windows) и подключайся к Arch:

```bash
ssh root@ТВОЙ_IP_АДРЕС
```
*(Принимай ключ — введи `yes`, затем пароль, который создал в пункте 1.2)*.
**Теперь ты можешь просто копировать и вставлять команды ниже!**

---

## Шаг 3: Разметка диска

Прямо в SSH-сессии запусти разметку:

1.  `lsblk` (найди свой диск, допустим это `nvme0n1`).
2.  `cfdisk /dev/nvme0n1`
    * Тип: **gpt**.
    * Создай раздел 1GB, тип **EFI System**.
    * Создай всё остальное место, тип **Linux root**.
    * **Write** -> `yes` -> **Quit**.

---

## Шаг 4: Магия автоматизации
Теперь просто копируй этот блок целиком и вставляй в терминал:

```bash
# 1. Скачиваем скрипты
curl -O https://raw.githubusercontent.com/Salamander5876/Arch/refs/heads/main/mount.sh
curl -O https://raw.githubusercontent.com/Salamander5876/Arch/refs/heads/main/install.sh
chmod +x mount.sh install.sh

# 2. Правим конфиг монтирования
# Узнаем имена разделов через lsblk и вписываем их в nano
nano mount.sh
```

**В Nano исправь:**
* `DISK_ROOT="/dev/sda2"` (например, `nvme0n1p2`)
* `DISK_EFI="/dev/sda1"` (например, `nvme0n1p1`)
* *Ctrl+O, Enter, Ctrl+X.*

**3. Запускаем установку:**
```bash
./mount.sh && ./install.sh
```

---

## Шаг 5: Перезагрузка
Когда скрипт дойдет до финала:

1.  `umount -R /mnt`
2.  `reboot`

## Чек-лист после первого входа (dark / 123123)

### 1. Эстетика и система
* Зайди в **System Settings** -> **Appearance** -> **Global Theme** -> **Breeze Dark**.
* Обновись: `sudo pacman -Syu`

### 2. Проверка софта
Все твои хотелки уже должны быть на месте:
* **Браузеры:** Firefox и Firefox Developer Edition.
* **Код:** VS Code, Node.js, Python, Git.
* **Контейнеры:** `sudo docker ps` (служба уже включена скриптом).
* **Связь и отдых:** Telegram, Steam, qBittorrent.

### 3. Инструменты
* **Hiddify:** Запусти из меню приложений, он подтянет все зависимости.
* **Архиваторы:** `unrar`, `p7zip` и `unzip` уже в системе, Dolphin (проводник) будет открывать любые архивы сам.

**Совет:** Если тебе нужно поставить что-то еще, чего нет в обычном магазине, используй AUR: `yay -S название`. Например, если захочешь Discord: `yay -S discord`.

Удачного полета на Arch! Теперь у тебя есть полностью кастомная система, собранная своими руками.

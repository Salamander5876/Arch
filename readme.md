Поздравляю с переходом на Arch! Это отличный шаг для программиста. Чтобы всё прошло гладко и без «кирпичей», вот пошаговый план действий, когда у тебя в руках флешка с Arch Linux.

---

## Шаг 0: Подготовка (из Windows или другой системы)
1. **Запиши ISO:** Используй [Rufus](https://rufus.ie/) (выбирай режим **DD**) или [Ventoy](https://www.ventoy.net/).
2. **BIOS:** Отключи **Secure Boot** (Arch его не любит «из коробки») и убедись, что стоит режим **UEFI**, а не Legacy/CSM.

---

## Шаг 1: Загрузка и Интернет
Загрузись с флешки. Ты увидишь консоль. Первым делом нужен интернет:

* **Если кабель:** Интернет подцепится сам. Проверь: `ping google.com`.
* **Если Wi-Fi:** 1. Введи `iwctl`.
    2. `device list` (узнай имя, обычно `wlan0`).
    3. `station wlan0 scan`.
    4. `station wlan0 get-networks`.
    5. `station wlan0 connect ИМЯ_СЕТИ` (введи пароль).
    6. `exit`.

---

## Шаг 2: Разметка диска (Самый важный этап)
Твой скрипт `mount.sh` **не создает** разделы, он их только форматирует. Тебе нужно создать их вручную:

1. Введи `lsblk`, чтобы понять, как называется твой диск (например, `nvme0n1` или `sda`).
2. Запусти редактор: `cfdisk /dev/nvme0n1`.
3. Выбери тип таблицы: **gpt**.
4. Создай минимум два раздела:
    * **Раздел 1:** 512 MiB или 1 GiB. Тип: **EFI System**. (Это будет твой `/boot`).
    * **Раздел 2:** Всё оставшееся место. Тип: **Linux root (x86-64)**. (Это твой `/`).
5. Выбери **Write**, подтверди (напиши `yes`), затем **Quit**.

---

## Шаг 3: Проверка имен разделов
Снова введи `lsblk`. Теперь у тебя должны появиться разделы, например `nvme0n1p1` и `nvme0n1p2`.
**Запомни их!** Тебе нужно будет вписать их в `mount.sh`.

---

## Шаг 4: Запуск твоих скриптов
Теперь вводи ту самую команду, которая скачает всё с твоего GitHub:

```bash
curl -O https://raw.githubusercontent.com/Salamander5876/Arch/main/mount.sh && \
curl -O https://raw.githubusercontent.com/Salamander5876/Arch/main/install.sh && \
chmod +x mount.sh install.sh && \
nano mount.sh
```

**В редакторе NANO:**
1. Найди строки `DISK_ROOT` и `DISK_EFI`.
2. Исправь их на свои (например, `DISK_ROOT="/dev/nvme0n1p2"` и `DISK_EFI="/dev/nvme0n1p1"`).
3. Нажми `Ctrl+O`, `Enter`, `Ctrl+X`.

**Запуск процесса:**
```bash
./mount.sh && ./install.sh
```
*Теперь можешь пойти заварить чай. Скрипт сам поставит ядро, Plasma, Docker, Steam и весь остальной софт.*

---

## Шаг 5: Финал и перезагрузка
Когда скрипт закончит работу и напишет «Установка завершена», делай следующее:

1. `umount -R /mnt`
2. `reboot`

Вытаскивай флешку. Тебя встретит экран входа **SDDM**.
* Выбирай пользователя **dark**.
* Пароль: **123123**.

---

## Что сделать сразу после захода в систему?

1.  **Обнови ключи и систему (на всякий случай):**
    `sudo pacman -Syu`
2.  **Проверь Docker:**
    `sudo docker ps` (убедись, что работает).
3.  **Настрой Hiddify:**
    Найди его в меню приложений и добавь свои конфиги.
4.  **Эстетика:**
    Зайди в *System Settings -> Appearance -> Global Theme* и выбери **Breeze Dark** (или скачай любую другую через кнопку "Get New Global Themes").

**Совет для программинга:** Поскольку ты на Arch, если тебе понадобится какая-то библиотека или прога, которой нет в обычном магазине, просто пиши `yay -S название_пакета`.

Если на каком-то этапе (особенно на разметке) возникнут сомнения — пиши, я тут. Удачи!
